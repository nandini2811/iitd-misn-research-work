# Week 3 - CNN from Scratch

## Objective

Implement the forward and backward pass of a Convolutional Neural Network (CNN) from scratch using Python and train it on the CIFAR-10 dataset.

## Dataset

* CIFAR-10
* 10 image classes

## Training Results

* Epochs: 20
* Final Loss: **1.9759**
* Final Test Accuracy: **30.4%**

## Files

* `Q1 - CNN scratch.py` - CNN implementation from scratch.

## Outcome

Successfully implemented and trained a CNN from scratch on the CIFAR-10 dataset, achieving a final test accuracy of **30.4%** after 20 epochs.
